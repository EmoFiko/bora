# Bora için site

Bu site Bora için hazırlanan özel bir teşekkür sayfasıdır.

## Canlı link

👉 https://EmoFiko.github.io/bora/

## Nasıl çalışır

- `index.html` dosyasındaki `CONFIG` bloğunu kendi bilgilerine göre düzenleyebilirsin.
- `receiver`: karşıdaki kişinin adı
- `sender`: senin adın
- `startDate`: ilişkinin başlangıç tarihi
- `reasons`: tam 10 sebep listesi
- `spaceApps`: Space Apps anıları
- `letter`: mektup paragrafları
